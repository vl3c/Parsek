## 7. Gaps, and the cheapest way to close each

1. **No fixture has a two-slot RP with one slot ALIVE and SUB-ORBITAL, and none carries a
   predicted tail** - so the continuation system has no fixture subject at all. Cheapest: a fourth
   generator (`rewind-suborbital`) = `RewindB9Fixture` with
   `WithTerminalState((int)TerminalState.SubOrbital)` on the non-focus slot plus
   `AddOrbitSegment(..., isPredicted: true)`. One file, one `run.py` preset row, one
   `hlib.INJECTED_RECORDINGS` entry. Also unblocks `MergeReFlyToSubOrbitalKeepsSlotOpen`.
2. **No mission leaves a half ALIVE and SUB-ORBITAL at scene exit on purpose.** GS-1 flight 3 did
   it by accident (`GS-1:299, :376, :387`). Cheapest: a GS-1 spec variant that shortens the
   `SIBLING-DOWN` wait (`GS-1:857`) and exits to the Space Center while the booster still descends
   - `missionParams` plus a new spec, no mission-code change.
3. **No lane re-flies slot 0 then slot 1 of the same RP** (`S1.5` is the only `slot = "0"` lane;
   every other hard-codes `slot = "1"`). Cheapest: one spec driving
   `InvokeRewind slot=0` -> `AnswerMergeDialog` -> `InvokeRewind slot=1` -> `AnswerMergeDialog` on
   `rp_b9_root`. No new verb; the second rewind needs the RP to survive the first merge, which is
   precisely the behaviour worth measuring.
4. **`AnswerMergeDialog choice = "seal"` is never exercised**, and it needs a >= 3-button dialog -
   exactly the dialog an unfinished sub-orbital half produces. One driver step in the gap-2 lane.
   Caveat: `discard` on a journal-active dialog presses MERGE (single forced button,
   `MergeDialog.cs:421-430`), so a discard lane must not sit on that path. Likewise **`SealSlot`'s
   D9 `rp=` + `slot=` spelling has zero consumers** - one more step in the gap-3 lane.
5. **No lane arms a render tracer during an ACTIVE re-fly session, and no lane in this set declares
   `[expectations.renderComposition]`.** S4.1-S4.4 set only `verboseLogging`; `ghostRenderTracing`
   is armed only by GS-4/6/7/8 (rewind-to-LAUNCH, no live session); `mapRenderTracing` by no rewind
   lane at all; `EnterMapView` / `ExportRenderManifest` by none (GS-4 calls `EnterMapView` only as a
   RECORDED, never-fatal mission step). Cheapest: those settings and verbs plus a
   `renderComposition` block on an S4.x-shaped lane, with a `LoadGame scene=trackstation` tail for
   the TS half.
6. **Mid-re-fly quickload is a refusal, not a resume** (section 3), and **the 12 session-gated
   in-game `Rewind` cells have never executed**. Cheapest, no guard change: add
   `RunTests category = "Rewind"` AFTER the `InvokeRewind` in an S4.x clone so those 12 -
   `F5MidReFlyResume` and `MergeReFlyToSubOrbitalKeepsSlotOpen` included - run with a session live
   for the first time. Highest value per line of spec in this list.
7. **D9 `load-time-sweep` is the one uncovered cell** and its honest driver is the RESERVED
   `CrashAfterJournalPhase`; short of promoting it, a second `LoadGame` after a merge is the cheap
   approximation. Seven further D9 cells have exactly ONE claiming lane each (section 4).
8. **`H58` drives `InvokeRewindToLaunch` twice and `SealSlot` once but banks no `dimensionsCovered`

9. **D18 is 4/12** and every uncovered cell needs a real ghost-to-vessel spawn inside a run, which
