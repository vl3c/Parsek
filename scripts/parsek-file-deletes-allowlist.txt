# Parsek-file delete grep gate (scripts/grep-audit-parsek-file-deletes.ps1).
#
# Files under Parsek/Recordings, Parsek/RewindPoints and Parsek/Saves are deleted only
# by ParsekFileCollector (design-load-restores-the-save.md 4.5): a file stays while any
# save in the folder or the running game names it. The gate counts the four delete-family
# tokens (File.Delete( / File.Move( / File.Replace( / Directory.Delete() on raw source
# lines in Source/Parsek and fails on a file that is not listed here, or on a listed file
# whose count differs from its pin.
#
# Entry forms (repo-relative, forward slashes, '#' starts a comment):
#   <file>          owner: any count
#   <file> <n>      pinned: exactly n hits; every hit was read and touches no file in
#                   those three directories (the rationale follows each entry)
#   <dir>/          prefix: every file underneath, any count (test-only code)
#
# One pinned file deletes a WHOLE save folder rather than a file inside it: the NewGame
# seam verb (automation only) replaces saves/<save> the way stock's New Game overwrite does.
# Every save that could name a sidecar goes with the folder, so the collector's rule (a file
# stays while a save names it) has nothing left to protect there.
#
# A new delete site in a pinned file moves its count: re-read it, and when it touches one
# of the three directories route it through the collector instead of raising the pin.
